# Educational design

## Learning loop

Each activity follows a short loop suitable for young learners:

**Goal → Build → Predict → Run → Observe → Explain → Modify**

The UI should never require a learner to configure torque, inertia tensors, or solver iterations for a basic mission. Those concepts can be revealed later as optional advanced layers.

## Visual language

- Red/blue ports: electrical path.
- Yellow ports: rotational/mechanical path.
- Green success states: a subsystem is active.
- Labels use everyday Vietnamese first, technical term second when useful.

## Initial concepts

1. Closed/open electrical circuit.
2. Energy conversion: battery → electricity → motor → rotation.
3. Transmission: shaft carries rotation.
4. Output interchangeability: fan/drill/wheel.
5. Gear ratio: speed vs. torque trade-off.
6. Sensor/controller logic in later lessons.

## Safety framing

This is a simulation. Real motors, batteries, tools and rotating mechanisms can present electrical, heat, pinch, entanglement or sharp-tool hazards. Physical build activities should be age-appropriate and supervised.
